# Study Guide Github Foundations
Notes taken in preparation for the GitHub Foundations certificate

## Repository Structure
- content.md: Contains the detailed study notes and key concepts covering the GitHub Foundations certification
- questions.md: Contains practice questions to test your knowledge based on the material in content.md
- answers.md: Contains the answer key and explanations for the questions in questions.md
